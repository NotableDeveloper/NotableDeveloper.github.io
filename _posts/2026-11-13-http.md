HTTP(Hyper Text Transfer Protocol)은 7계층에서 동작하는 프로토콜이며, 요청과 응답으로 메시지가 정의되어 있다. 또, 메시지들은 패킷의 데이터 필드에 포함되어 있다. 

요청 메시지는 클라이언트가 서버에게 보내는 메시지이며, 응답 메시지는 서버가 클라이언트에게 보내는 메시지이다. 요청 메시지는 Get, Post, Delete, Put, Patch와 같은 것들이 있으며, 응답 메시지는 상태 코드라는 것을 포함하여 클라이언트에게 반환된다.

# HTTP Method

- Get
    
    서버가 가진 리소스를 조회하는 메서드이다.
    
- Post
    
    서버에게 데이터를 전송하는 메서드이며, 새로운 리소스를 등록할 때 주로 사용한다.
    
- Delete
    
    서버가 가진 리소스를 삭제하는 메서드이다.
    
- Put
    
    요청 데이터를 사용하여 서버에 **새로운 리소스를 생성**하거나, 대상 리소스를 나타내는 데이터를입력으로하여 기존의 리소스를 **대체**하는 메서드이다.
    
- Patch
    
    서버가 가진 리소스를 **부분적으로 변경**하는 메서드이다.
    

# HTTP 응답 코드

- 200
    
    요청이 성공적임을 나타낸다.
    
- 3xx
    
    원하는 문서가  되었음을 의미한다.
    
- 4xx
    
    클라이언트 측의 에러를 나타낸다. (잘못된 리소스 접근 등)
    
- 5xx
    
    서버 측의 에러를 나타낸다.
